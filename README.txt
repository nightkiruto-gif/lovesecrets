LOVESECRETS — نسخة أولية
الملفات: index.html, style.css, app.js, FIRESTORE_RULES.txt

إعداد Firebase:
1. افتح https://console.firebase.google.com وأنشئ مشروعًا.
2. أضف Web App من إعدادات المشروع وانسخ firebaseConfig.
3. في app.js استبدل PASTE_API_KEY_HERE وPASTE_PROJECT_ID_HERE وPASTE_APP_ID_HERE بالقيم الحقيقية.
4. أنشئ Cloud Firestore من Build > Firestore Database.
5. افتح Rules، ألصق محتوى FIRESTORE_RULES.txt واضغط Publish.
6. ارفع الملفات إلى مستودع GitHub. في Settings > Pages اختر Deploy from a branch، ثم main و /(root) واحفظ.

مهم: هذه نسخة MVP تجريبية. قواعد الوصول العامة تعني أن من يعرف الرمز يستطيع قراءة الاختبار وإجابات التصحيح. لا تضعوا كلمات مرور أو معلومات مالية أو أسرارًا حساسة. التصحيح يعمل فقط للأسئلة المخصصة ذات الإجابة المحددة؛ الأسئلة الجاهزة مفتوحة ولا تملك إجابة واحدة صحيحة. أضف حماية من الإساءة قبل نشر واسع.
